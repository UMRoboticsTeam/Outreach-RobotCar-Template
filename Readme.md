# Outreach-RobotCar-Template

**Description**:
This project is used as the source for the UMRT Sumo Bots coding activity. 

**Source Files provided**:
- Main_instructor_copy.ino: Example solution for use by workshop instructors
- Main.ino: Blank template to be used in workshops.

**Functions Provided**:

Movement:
    - Forward
    - Reverse
    - turn Right
    - turn left
Sensor:
    - Ultrasonic distance measurement
    - LineTracker
